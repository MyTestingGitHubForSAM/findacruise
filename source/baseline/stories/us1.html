User story 1

Story 1 — Access the Find a Cruise component

As a consumer, I want to see the Find a Cruise component on the Home Page, so that I can begin searching for a cruise without navigating to another page.

Dependencies: None · foundation for US2–US5

Scope: Home Page component; illustrative data and existing design-system assumptions.

Why it matters

Consumers can begin a cruise search from the Home Page, with no extra navigation step.

Acceptance criteria

US1 · AC1#

AC1 — Display the component

Scenario: Display the Find a Cruise component

Given the consumer navigates to the Royal Caribbean Home Page

When the page loads successfully

Then the Find a Cruise component is displayed

And its placement follows the approved Home Page design

US1 · AC2#

AC2 — Display the initial filter states

Scenario: Display the component without selected filters

Given the consumer opens the Home Page

When the Find a Cruise component is displayed

Then the Destination filter displays "Any Destination"

And the Departure Port filter displays "Any Departure Port"

And the Departure Date filter displays "Any Date"

US1 · AC3#

AC3 — Display the required controls

The component includes:

* A Destination control identified by Cruising To.

* A Departure Port control identified by Departing From.

* A Departure Date control identified by Leaving.

* The calendar affordance shown in Visual Reference 2.

* A primary action labeled Search Cruises.

US1 · AC4#

AC4 — Interpret default values as unrestricted criteria

Scenario: Display an unrestricted initial search state

Given the consumer has not interacted with any filter

Then no destination restriction is active

And no departure port restriction is active

And no departure date restriction is active
